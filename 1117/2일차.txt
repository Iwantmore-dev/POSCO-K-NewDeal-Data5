변수란 무엇인가?
변수는 값에 붙이는 이름임. 숫자 말고도 글자나 참 거짓을 담을 수 있음.
다시 부르기/ 바꾸기/ 계산 가능함.

마치 바구니에 이름표를 붙이는것과 같음. 변수명은 이름, 바구니 안에 값은 변화가 가능함.


할당문 작성법
변수이름 = 값 으로 할당
ex: temp = 25 # temp라는 변수에 25라는 값을 할당함.
name = "센서A" # 글자는 ""가 필요하고 name에 센서A를 할당
=는 같다는 뜻이 아니라 저장하는 명령임
x = x+5는 오른쪽을 먼저 계산한 다음 다시 x에 저장하게 함.
같다라는 의미는 ==로 사용함.

if 2번 라인의 temp=25이고 10번에서 재할당을 하여 temp = 30이라면 3~9까지는 temp는 25 10번 라인부터는 30이 됨.

temp =25
print(temp)는 25를 출력
print("temp")는 temp라고 출력

변수 이름 규칙이 존재함.
1.영문자/숫자/밑줄 가능/_대신-는 불가능
2. 숫자로 시작 불가
3. 중간 공백 불가, 두 단어는 밑줄로 연결

예약어와 피해야할 이름존재함.
if와 for, true는 이름으로 불가능함.
print나 type같은 함수 이름도 금지
편집기에서 자동으로 색이 입혀진 단어는 이름으로 사용하지 않는다.

snake_case
pascal_case
camel_case
의 형태가 있음.

ilovekorea라는 변수가 있다고 치자.
snake case는 가시성을 위해 i_love_korea로 작성할것임.
camel_case는 iLoveKorea라고 작성함.
pascal_case는 Ilovekorea라고 작성함.(첫 문자 대문자.)

python은 snake_case를 따름.

변수에 다른 변수름 담는경우
a = 10 > a에 10이 저장됨.
b = a > b에 a값인 10이 들어감.
a = 99 > a가 99로 재할당됨.

print(b) > a가 변경되었어도 b는 그대로 10을 출력하게됨.
한 줄에 여러 변수 선언이 가능함
x, y, z = 10, 20, 30

변수를 선언하고 사용하다가 필요시 변경한다
좋은 변수명이란 규칙을 지키고 이름을 보기만 해도 무슨 값인지 알 수 있어야함.

자료형에 대해서
숫자,글자,참or거짓 등이 존재함

정수형 int(integer)
ex : count = 3, age = 28, zero = 0 즉 소수점이 없는 수
실수형 float(소수존재)
temp = 25.5, height = 178.1

a= 5면 int이나 b = 5.0이면 float임.

문자열형 str(string)
name = "센서 A"
empty = ""
만약 문자열 내에 따옴표를 넣고 싶으면 바깥은 다른 종류의 따옴표를 사용
ex : "'안녕'" or '"안녕"'
문자열간 +는 문자를 잇는 게 됨
ex :  print("3"+"5") = 35

불린형 bool(boolean)
ok = True
no = False
true나 false는 대문자로 작성할것.

print(3>2) #True
print(5 ==5) # True
print(1>10) #False

type()함수
print(type(25)) #25는 정수이므로 int를 출력함

type()을 통해 자료의 형식을 파악가능

print(0.1+0.2) # 0.3000000004 처럼 극도로 작은 오차발생가능하므로 round()를 통해서 자릿수를 맞출 수 있음.
