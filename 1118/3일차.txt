input() 함수
input은 사용자의 입력을 기다리는 함수이다.

입력한 결과를 변수에 저장함
name = input("이름 : ")
print(name)
input의 결과는 항상 문자열이다.
예를 들어
age = input("나이 : ")에 25를 입력하면 숫자처럼 보이지만
print(type(age))를 하면 str타입으로 나온다. 즉 ""이 자동으로 들어간다고 생각하자.

int()를 사용하면 정수로 변환이 가능하다.
age = int(input("나이 : "))
print("내년에는", age+1, "살")

비슷하게 float()로 실수 변환, str()로 문자열로 변환이 가능하다.

age = int(input("나이 : ")) 여기에 스물 다섯이라고 입력한다면 스물다섯은 int가 아니므로 에러가 나게됨.

진행의 흐름을 익혀둬야함
입력+변환 계산 출력의 흐름으로 이해할것.

빈 문자열 ""과 공백 문자열 " "은 다르다. 1개의 차이가 있음.
문자열을 작은따옴표 또는 큰따옴표로 감쌀 수 있으며, 문자열 내부에서 바깥쪽과 동일한 따옴표를 사용하려면 역슬래시로 이스케이프 처리할 수 있다. 서로 다른 종류의 따옴표는 별도 처리 없이 사용할 수 있다.
이스케이프 처리라고 하는데 특수문자를 표현하거나 혹은 문자의 의미를 변경할때 사용한다.

sep과 end처럼 print에서 제공하는 매개변수도 존재한다.

추가로 알게된 사실인데 변수 선언시 print로 선언하면 안된다.

인덱싱
위치번호로 글자를 하나 꺼내고자 할때 인덱싱을 사용함.
HELLO
01234
글자의 첫 번째는 0으로 시작함. 다른 예시로 python은 p0 y1 t2 h3 o4 n5 가되는것.
만약 음수의 경우 음수는 뒤에서부터 시작 즉, python은 -6-5-4-3-2-1이 되는 것.

word[0] == w, word[1]==o가 됨.
없는 번호를 사용하게 되면 indexerror가 뜸.
변수선언을 하고 사용해도 되지만 "python"[2]처럼 사용해도 됨.

설비코드의 첫 글자로 종류를 빠르게 확인하는데 사용하기도 함.
PM-001
PM-002
PM-003
이런식으로 늘어나는경우 MS-001,MS-002 등과 구분이 빠르게 가능.

슬라이싱 문법[start:end]
word[1:4]는 1,2,3번 자리 즉, 시작 포함 끝 제외하여 가져오는것
0부터 시작하더라도 동일함.

word[1:4]는 1,2,3이므로 wor가 됨.
또한 앞번호를 생략할 수 있는데 이때는 0과 마찬가지처럼 동작함.
word[:]는 모두 가져오는것. 음수의 경우에는 word[-3:]처럼 동작
콜론이 2개 등장하면 step 즉 건너뛰며 자르기이다.
word[::2]는 0,2,4번 2칸씩 가져오는 것.[몇번부터:몇번직전까지:간격]
"python"[1::2] ==yhn
"python"[::-1]은 단어가 뒤집어짐. nohtyp가 됨
슬라이싱은 범위를 넘어도 오류가 나진 않음.

len()이란 함수는 문자열의 글자 수를 숫자로 알려줌
len('python') == 6
공백도 한 글자로 센다. 빈문자열""의 길이는 0으로 카운트함.
len()은 입력값이 규칙에 맞는지 점검하는 용도로 사용함. 예를 들어 휴대폰 번호 11자리나 설비 코드 7자리가 맞는지 확인하는 용도임.
in은 함수는 아니긴함. in은 특정 단어가 들어가있는지 TF로 확인하는것.
'thon'in'python' ==True, 'L'in'python' ==False, in혹은 not in 뒤에 오는 문자열에 특정 단어 들어있는지 확인하는것이므로 주의할것.


count()는 특정 글자나 단어가 몇번 나오는지 세는 함수임
find()는 특정 글자가 처음 나오는 위치번호를 알려주는 함수이다.
str.find('찾고자하는것')으로 작성해야함. 찾은 위치를 슬라이싱 끝 번호로 활용할 수 있고, 못찾았다면 -1을 도출함.
find('찾고자하는것',찾으려는 시작 위치)로도 가능

email = 'hong@company.com'
at = email.find('@') #find로 @의 위치는 4가 나올것이고 at에 4가 할당됨
index()도 find와 동일하지만 없는경우 find와 다르게 오류로 멈추게됨.
사용방식도 index는 find처럼 string.index()로 사용함.

startswith()는 True나 False를 반환함.
