문자열.메서드이름() 형태로 호출함
괄호를 반드시 붙여야하고 추가 정보가 필요하면 괄호 안에 인자를 넣음.
ex: prob.count()

word.upper()를 해도 word변수 자체는 그대로임. 결과를 쓰고싶다면 새로운 변수를 선언해야함.

upper() 영문 글자를 모두 대문자로 만들어줌.

ex: python.upper() -> PYTHON
반대로 lower()도 있음.

대소문자 무시하고 비교하고 싶을때 PYTHON.lower() == python.lower() 이런식으로 활용가능

isupper(), islower()는 대문자인지 소문자인지 물어보는 함수

공백이 데이터를 망친다.
눈에 안보이는 앞 뒤 공백이 데이터를 망가뜨림.

'정상'과 '정상 '은 다름.
데이터를 다루기 전에 공백 제거가 거의 필수임.

strip()은 공백을 제거함. lstrip()은 왼쪽, rstrip()은 오른쪽 공백만 제거함.
strip('#')은 #을 제거 즉, strip괄호 안에 문자를 넣으면 제거.
strip이라고 만능은 아님. 중간 공백 즉, 글자 사이 공백은 지울 수 없음. ->replace로 제거

ex: ' NORMAL '을 소문자로 만들면서 공백도 제거 하고 싶으면 메서드 체이닝 사용
' NORMAL '.strip().lower() 처럼 체이닝
다만, text.strip() 하면 문자열로 반환되나, count()같은걸 사용하면 int가 반환되므로 lower사용 불가.
따라서 매서드의 순서도 중요함. 읽는 순서는 왼쪽에서 오른쪽으로 진행됨.
메서드 사용이 끝났다면 다른 함수로 받아올것.

capitalize는 첫 글자 대문자로 만들어줌.


replace() 단어를 바꿔줌.
괄호 안에 바꿔질 글자, 새로 넣을 글자 순으로 순서 지켜야함. strip이나 upper lower처럼 변수에 다시 받아야함.

replace(' ','')는 중간 공백가지 모두 제거
replace도 체이닝 가능.
replace는 데이터의 표기를 통일하고 기호를 제거하기 위해 사용한다. 3,000처럼 ,로 인해서 int로 인식이 안될때 ,를 제거하여 int로 사용가능.

리스트. 여러 조각을 담을 수 있음. 대괄호 안에 값들을 쉼표로 나열함.
리스트는 여러가지 데이터형을 넣을 수 있음.
ex : [int, str, float, ...] 번호로 조각 하나를 꺼냄. split이라는 함수 배우기 전에 잠깐
a = [apple, pear, orange]일때 a[1] == pear
split()은 반환을 list로 반환해줌.

split()은 문자열을 리스트로 변환 할 수 있음. 구분자가 나오는 자리마다 잘라 리스트에 넣는데 기본적으로는 공백임. 구분자는 설정 가능

ex: i love python 에서 리스트화 하면 [i,love,python]이 된다.
'i love python'.split() == [i,love,python], ()내에 특정 문자열을 기준으로 구분가능

CSV한 줄 나눌때도 좋음
1,EQP-001,정상,25.3을 4조각으로 나눌 수 있음. csv데이터를 split으로 나눠가지기 쉬움

'1,eqp-001,정상,25.3'.split(',')

split maxsplit은 횟수 제한을 넣는것임.
'a-b-c-d'.split('-',1) ==[a,b-c-d]

join()합치기. 리스트의 여러 조각을 하나의 문자열로 합치는것
['a','b','c'] '-'.join(parts) 조각 사이에 하이픈을 끼움. join은 str형만 합칠 수 있음. join할때 리스트에 숫자 있으면 에러남.

특이하게도 .join 앞에 구분자가 옴.
